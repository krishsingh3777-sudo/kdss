Built for precision, not paperwork

Three things this platform gets right, so you don't have to build them yourself.

TIMING

High-precision timing engine

Every stimulus and response is timestamped with sub-millisecond browser timers, not wall-clock guesses — so reaction-time data is actually comparable across trials.

BUILDER

Visual experiment builder

Drag a task block onto the canvas and it becomes a live, playable experiment instantly — participants see it appear in their list right away.

PRIVACY

Secure & anonymous data

Participants join with a randomly generated ID — never a name or email — and results are scoped to your experiment only, keeping raw data anonymous by default.

Four ready-made tasks

Drop any of these onto the builder canvas to spin up a new study.

🎯

Reaction time

A circle turns from grey to green at a random interval — participants press space the instant it does.

🔢

Visual number test

A number flashes on screen; participants type it back as fast and accurately as they can.

🧠

Memory test

Four words appear briefly, then vanish — participants pick which one they actually saw from a mixed set.

🧮

Aptitude test

A 60-second sprint of addition, subtraction, multiplication and division — questions keep coming until time runs out.
